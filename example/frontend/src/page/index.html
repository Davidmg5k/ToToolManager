Workflow

How it works

Three steps: define your service, register it, and call it.

01

Define your Python service

service/user.py 
class UserService:
    """Manages user accounts."""

    def __init__(self, repo: UserRepository):
        self._repo = repo

    def create_user(self, user_name: str, email: str):
        """Creates a new user account."""
        user = User(user_name=user_name, email=email)
        self._repo.add(user)
        return user

    def get_users(self):
        """Returns all users."""
        return self._repo.list()
02

Register it with to_tool_manager

controller/__init__.py 
from to_tool_manager import Service, ErrorMap

def build_user_service(session) -> Service:
    repo = UserRepository(session)
    return Service(
        name="user_service",
        service=UserService,
        description="Manages user accounts.",
        error_map=(
            ErrorMap()
            .map(NotFoundException, category="not_found")
            .map(AlreadyExistsException, category="already_exists")
        ),
        args=(repo,),
    )
03

The LLM calls your service as a tool
